# Java Programming Projects

A collection of Java applications and coursework demonstrating object-oriented programming (OOP) principles, data structures, algorithm implementation, and graphical user interfaces (GUI).

## Projects Included

| Project | Description | Key Concepts |
| :--- | :--- | :--- |
| **Projectile Calculator** | Calculates horizontal and vertical positions of a projectile over time. | Math functions, input validation, control flow |
| **Weather Analyzer** | Logs and analyzes daily high/low temperatures to compute averages and extremes. | Arrays, loops, aggregate calculations |
| **Product Inventory** | Product management system handling both standard and perishable stock. | OOP Inheritance (`Super` / `Subclasses`), `ArrayList`, Date parsing |
| **Vaccine Tracker** | Manages vaccine records, pricing, quantities, and expiration details with formatted table output. | Encapsulation, constructors, string formatting |
| **Vet Patient GUI** | Desktop application form for registering veterinary patients and writing records to disk. | Java Swing (`JFrame`), event handling, layout managers, file I/O (`PrintWriter`) |

## Tech Stack
* **Language**: Java
* **Tools**: Eclipse IDE, Git / GitHub Desktop
